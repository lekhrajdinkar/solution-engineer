| Diagram                         | Best used for                                             |
| ------------------------------- | --------------------------------------------------------- |
| **Flowchart**                   | Process flow, decisions, request routing                  |
| **Architecture diagram**        | Cloud services, infrastructure and resource relationships |
| **Block diagram**               | Clean, manually controlled system architecture            |
| **Sequence diagram**            | Request flow between services over time                   |
| **C4 diagram**                  | System context, containers, components and deployment     |
| **State diagram**               | Object or service state transitions                       |
| **Class diagram**               | Classes, interfaces and relationships                     |
| **Entity Relationship diagram** | Database tables and relationships                         |
| **Swimlane diagram**            | Workflow divided by teams or services                     |
| **Requirement diagram**         | Requirements and their dependencies                       |
| **Packet diagram**              | Network-packet structure                                  |
| **Git graph**                   | Branch, commit and merge history                          |
| **Gantt chart**                 | Project timelines                                         |
| **Kanban**                      | Work items grouped by status                              |
| **User journey**                | User steps and experience                                 |
| **Mind map**                    | Topic breakdown and brainstorming                         |
| **Timeline**                    | Events arranged chronologically                           |
| **Pie chart**                   | Percentage distribution                                   |
| **XY chart**                    | Bar and line charts                                       |
| **Quadrant chart**              | Four-quadrant comparisons                                 |
| **Sankey diagram**              | Flow volume between components                            |
| **Radar chart**                 | Comparing multiple metrics                                |
| **Treemap**                     | Hierarchical proportional data                            |
| **Venn diagram**                | Overlapping concepts                                      |
| **Ishikawa diagram**            | Root-cause or fishbone analysis                           |
| **Wardley map**                 | Strategic capability mapping                              |
| **Cynefin diagram**             | Problem and decision classification                       |
| **Event modeling**              | Events, commands and system workflows                     |
| **TreeView**                    | Folder or hierarchical tree structures                    |
